# Сжатие и конвертация изображений (Image Compression)

## Инструкция

Когда пользователь просит сжать, конвертировать или оптимизировать изображение (или папку с изображениями):

1. **Проверьте зависимости**: для работы скрипта в системе должны быть `magick` (ImageMagick) и `pngquant`.
   Если их нет, предложите пользователю установить (например, `brew install imagemagick pngquant`).
2. **Используйте скрипт**: запустите глобальный Node.js скрипт для обработки файлов.
   
   Формат запуска:
   ```bash
   node ~/.codex/skills/image-compression/scripts/compress.js <путь_к_файлу_или_папке> [путь_к_папке_вывода] [--ext .webp]
   ```

   - `<путь_к_файлу_или_папке>`: Абсолютный или относительный путь к исходному фото или папке с фото.
   - `[путь_к_папке_вывода]`: Опционально. Если не указать, результат сохранится в папку `compressed` рядом с оригиналом.
   - `[--ext .webp]`: Опционально. Желаемое расширение на выходе (по умолчанию `.webp`). Поддерживаются: `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`.
3. **Удалите исходный файл после успешного сжатия**: скрипт не удаляет оригинал автоматически — это нужно сделать вручную после проверки, что новый файл создан и имеет ненулевой размер.

   - Удаляй **только** исходный файл, который был обработан (например, `hero.png` после получения `hero.webp`).
   - Удаление — **только после успешного** завершения скрипта для этого файла.
   - Если выходной файл лежит в другой папке (например, `compressed/`), перенеси результат в целевую директорию (если нужно), затем удали оригинал.
   - При пакетной обработке папки удаляй каждый исходник сразу после успешной конвертации соответствующего файла.
   - Если в коде есть импорты на старый путь/расширение — обнови их на новый файл **до** или **сразу после** удаления оригинала.

## Примеры

**Пример 1: Одиночный файл (в webp)**
```bash
node ~/.codex/skills/image-compression/scripts/compress.js src/assets/hero.png src/assets --ext .webp
# после успеха — удалить src/assets/hero.png
```

**Пример 2: Папка с файлами (в avif)**
```bash
node ~/.codex/skills/image-compression/scripts/compress.js src/assets/images public/images --ext .avif
# после успеха — удалить каждый исходный файл из src/assets/images
```

## Алгоритм работы скрипта (для справки)
Скрипт работает по проверенному алгоритму:
1. Конвертация исходного файла во временный `png` с помощью `magick`.
2. Сжатие временного `png` с помощью `pngquant`.
3. Конвертация сжатого `png` в итоговый формат (например, `webp`) с помощью `magick`.
4. Удаление временных файлов.
