# Local docs

Read `docs/agents/domain.md` and follow it. When that file is missing, read `GLOSSARY.md` or `GLOSSARY-MAP.md` at the repo root and any ADRs under `docs/adr/` that touch the area. A missing glossary or ADR is fine: continue.

Use the glossary's terms in test names. When a decision conflicts with the behavior under test, say so before writing the test.
